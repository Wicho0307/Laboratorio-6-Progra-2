# Ejercicios 2 y 5 - Cursos

- **Ejercicio 2:** diseño OpenAPI para administrar cursos universitarios.
- **Ejercicio 5:** implementación del diseño mediante Java, Spring Boot y almacenamiento en memoria.

El archivo `cursos-api.yaml` contiene las rutas, firmas de request y response, modelos y códigos HTTP del diseño.

Archivos del modelo:

- `Curso.java`
- `EstadoCurso.java`

El controlador correspondiente se encuentra en `controller/ejercicio2/CursoController.java`.
