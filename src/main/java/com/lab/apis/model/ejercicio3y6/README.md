# Ejercicios 3 y 6 - Reservas

- **Ejercicio 3:** diseño OpenAPI para administrar reservas de hotel.
- **Ejercicio 6:** implementación del diseño mediante Java, Spring Boot y almacenamiento en memoria.

El archivo `reservas-api.yaml` contiene las rutas, firmas de request y response, modelos y códigos HTTP del diseño.

Archivos del modelo:

- `Reserva.java`
- `EstadoReserva.java`

El controlador correspondiente se encuentra en `controller/ejercicio3/ReservaController.java`.
