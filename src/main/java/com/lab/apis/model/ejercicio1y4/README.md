# Ejercicios 1 y 4 - Libros

- **Ejercicio 1:** diseño OpenAPI para administrar los libros de una biblioteca.
- **Ejercicio 4:** implementación del diseño mediante Java, Spring Boot y almacenamiento en memoria.

El archivo `libros-api.yaml` contiene las rutas, firmas de request y response, modelos y códigos HTTP del diseño.

Archivos del modelo:

- `Libro.java`
- `EstadoLibro.java`

El controlador correspondiente se encuentra en `controller/ejercicio1/LibroController.java`.
